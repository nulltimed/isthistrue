How we verify

The short version, for those who don't read much (the full methodology, with thresholds and models, is published in the project repository — all the code is free software):

1) When content is analysed, it is transcribed and an agent extracts its claims, separating verifiable facts from opinions. 2) If the content is mostly opinion, it goes to Off-Topic with no verdicts. 3) If it is factual, the community validates that it deserves verification (5 votes in 3 days). 4) Each claim is then checked against searches and linked sources, and gets a colour: 🟢 verified · 🟡 misleading or lacking context · 🔴 false · ⚪ not verifiable. 5) Every claim has its own wiki page with version history, sources and all its appearances. 6) Colours apply to claims, never to people. 7) Anyone can file a complaint; the authors of the content have a priority route (reply within 7 days).

The project does not promise “the truth”: it promises graded verifiability, a transparent methodology and reproducible sources.
